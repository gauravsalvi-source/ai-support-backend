Title: Who Is This App For 

The Outlink App is designed for Shopify store owners who want to sell external or affiliate products on their site. It helps merchants seamlessly integrate external product links by replacing the standard "Add to Cart" button with a custom link that redirects customers to the affiliate product page. This makes it an ideal solution for various types of online businesses.
Why Use Outlink?• Easy Setup – Quickly replace the "Add to Cart" buttons with external links.
• Flexible Customization – Adjust button text and design to match your store’s branding.
• Monetization Opportunities – Earn commissions through affiliate programs with seamless product listings.
• No Inventory Management – Sell products without worrying about stocking, shipping, or fulfillment.

Outlink makes it easy to turn your Shopify store into a powerful affiliate storefront by linking products directly to external websites. Here's how it works:

2. Add the Outlink App BlockFollow the steps mentioned in the installation guide&nbsp;to add the required app block to your theme.(Skip this step if the code is already added.)

Title: Add Update Product

The system provides two modes for adding or updating products:
1. Always Add New ProductsDescription: Every product in the data feed will be treated as a new product.
Behavior:

A new product entry will be created regardless of whether a product with the same SKU already exists.
This may result in duplicate products if SKUs are reused or already exist in the store.
Use Case: Best suited when importing a fresh batch of entirely new products or when SKU duplication is acceptable.
2. Add or Update Products Based on SKUDescription: Products will be added or updated by matching existing SKUs.
Behavior:

If a product with the same SKU already exists in the store, it will be updated with the latest data (price, inventory, title, etc.).
If the SKU does not exist, a new product will be created.
Use Case: Ideal for maintaining a clean catalog and avoiding duplicates by using SKUs as unique identifiers.

Title: How To See Click Tracking Data 

Click Tracking in Google Analytics:&nbsp;
Each click on the external button link is recorded as an event&nbsp;in Google Analytics with the following parameters:

• event_category&nbsp;= ‘Outlink’
• action&nbsp;= ‘Click’
event_label&nbsp;= 'Outlink-Click'.&nbsp;
value= External link URL
To see Click Tracking reports:

• Sign in to Google Analytics.
• Navigate to your view.
• Open Reports.
Select Engagement &gt; Events.
Select the date range from the top right corner and look up for event Name: Click.
After clicking click, drill down / explore events having &nbsp;Event Category = 'Outlink' and Event Label= 'URL'.
Note: Currently, the report does not give you a complete list or history of the event parameters, the top reports only show real-time reports or events within the last 30 mins. To see a complete report on Event Parameters, you need to contact the Google Analytics support team.
Click Tracking in Facebook Pixel:
Each click on the Amazon link is recorded as a custom event on Facebook Pixel with the following parameters:

• &nbsp;event&nbsp;= ‘OutlinkClick'
• custom parameter = 'ExternalLink'.
To see Click Tracking reports:

• Sign in with Facebook Ads Manager.
• Navigate to Events.
• Click on View Analytics.
• Go to Events (on the left sidebar menu).
• Drill down / explore events having &nbsp;Events = 'OutlinkClick'.

You can also see the click activity in the Analytics Real-Time &gt; Events panel.
* for click tracking multiple links check out the guide here.

Title: Link Masking

Link masking (or link cloaking) is a method to hide the destination website's URL and replace it with a clean URL.&nbsp;
Affiliate links usually consist of tracking codes that identify vital information about the referrer and the program. This makes the affiliate links as long URLs with a lot of parameters than most shoppers think of as nonsensical information.
You want the shopping experience to be as smooth as possible with trust being a critical factor. Trust applies not only to the affiliate storefront but also to the destination affiliate links placed on the site. You don’t want to instill any doubt in a reader before they click on an affiliate link.
Short, clean links inspire trust and make the visitors more likely to click them.
As an example, consider a link from Amazon:
https://www.amazon.com/dp/B08JCJMZS2?dchild=1&amp;keywords=gaming&amp;qid=1605604583&amp;sr=8-3&amp;tag=gamingboyyzz-20&amp;linkCode=ogi&amp;th=1&amp;psc=1
Outlink will mask the above link as:
https://outpage.co/shop/5930084532378
Notice that the second link looks better and more organized. By making them look prettier, people will be more inclined to click.
To activate Link Masking, go to Outlink dashboard &gt; Settings &gt; Link Masking &gt; Activate &gt; Save.

Title: Outlink Url Parameters

The URL parameter is a way to pass information about a click through its URL.&nbsp;
URL parameters are made of a key and a value separated by an equals sign (=) and joined by an ampersand (&amp;). The first parameter always comes after a question mark in a URL. For example:

http://example.com?product=1234&amp;utm_source=google
The Outlink app supports adding URL parameters to the external/affiliate links added via the app.
These parameters can be used for tracking clicks. This is especially useful for measuring campaign performance.
To add the URL parameters, simply go to Settings &gt; URL Parameters&nbsp;in the Outlink dashboard. Here, you can add the URL parameter Keys and Values.
You can add multiple URL parameters.
When shoppers click the Outlink button, these parameters will be attached to the external link before redirecting the user.
Note:

1. The URL custom parameters are available to Pro Plan users only.

2. On deactivating the switch, the system will fall back to redirecting users to an external link without URL custom parameters.

3. If the Outlink app is uninstalled, URL custom parameters will not work.
