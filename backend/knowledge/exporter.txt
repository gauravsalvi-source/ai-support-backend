Title: Product Export To Csv

With the Data Exporter app, you can export all the product data into a CSV file by selecting the fields you want in just a few clicks. For this, you simply need to create the task.
Steps to Export Data in Bulk
1. Go to the App dashboard &gt; Click on the New Export sub menus.&nbsp;
2. On the 'Create Task' page, the first step is to select the fields that you want to export. You can select more than one.
3. Next step is to select the products that you want to edit. You can select more than one condition. Click 'Next'.&nbsp;&nbsp;
4. The app will search for the items that match the conditions and provide the count.&nbsp;
5. Finally, provide the export name and email and click the Export Now button. The app will then send you the CSV file to the email address you provided, wherein you can then download the file.&nbsp;
Please check this video guide for the step-by-step process:
Note:&nbsp;
The exported CSV file link received via email or in the dashboard will expire in 24 hours.
With the Exporter app, you will be able to export the product metafield data for the products in your current store, however, you will not be able to add them to the products while uploading the same file in your other store.&nbsp;Shopify does not allow or support the feature.&nbsp;
Important Note:&nbsp;The app automatically deletes export product logs after 24 hours.

Daily Schedule

Automatically run the export every day at the selected time.&nbsp;
Weekly Schedule

Run the export on a selected day every week.&nbsp;Perfect for recurring weekly&nbsp;catalogue updates, scheduled reporting.
Monthly Schedule

Automatically run the export on a specific date each month.&nbsp;

View Scheduled Tasks: Navigate to the "Scheduled Tasks" tab to see upcoming exports.
Edit or Delete: You can modify or delete scheduled export tasks before they are executed.&nbsp;

Title: Send Export Files To Additional Recipients Using Cc

The Product Data Exporter app now supports adding up to 2 email addresses in CC while scheduling or sending export files. This enhancement makes it easier to share exported product data with team members, clients, or other stakeholders automatically.

How to Add CC Email Addresses?Navigate to the export configuration section.
Enter the primary recipient email address in the Email field.
In the CC&nbsp;field (Max 2 emails):Type the email address
Press Enter to add it
Repeat the same step to add a second CC email address.
Benefits of Using CC EmailsThe CC feature is useful for:

Sharing exports with multiple team members
Sending reports to managers or clients automatically
Keeping backup recipients informed
Improving collaboration across departments

Important NotesA maximum of 2 CC email addresses can be added per export task.
All entered email addresses must be valid email formats.
CC recipients will receive the same export file as the primary recipient.
The CC feature is available for both basic and pro plan.
