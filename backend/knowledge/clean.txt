Title: Dynamic Product Metafields

The Clean app allows creating tables that display the value of any product metafield created by other apps.&nbsp;
A.&nbsp;The product metafields can be displayed by adding the {{ cleantm.namespace.key&nbsp;}} dynamic data field in the input text. Here namespace.key&nbsp;needs to be replaced with the actual meta field namespace and meta field key names.
For example&nbsp;- If you have a metafield with the namespace 'instructions' and key 'wash' then to display the value of this metafield, add text {{ cleantm.instructions.wash&nbsp;}}. &nbsp;
You can combine Product Metafield Display Conditions with Dynamic Metafields to create powerful rules that display metafield data based on your rules.
Below are a few examples of product metafield representations that may be helpful.
Metafield TypeProduct Metafield RepresentationProduct{{ cleantm.custom.product.value }}Collection&nbsp;{{ cleantm.custom.collection.value }}Money{{ cleantm.custom.price.value | money }}
Single Line Text{{ cleantm.custom.stock.value }}Multi Line Text{{ cleantm.custom.specs.value | newline_to_br }}Rich Text{{ cleantm .custom.rich_text | metafield_tag }}Multi Line Text{{ cleantm.custom.alphanumeric.value }}Validations{{ cleantm.custom.validation.value }}Weight{{ cleantm.custom.product_weight.value }}Volume{{ cleantm.custom.volume.value }}Dimension{{ cleantm.custom.dimension.value }}Decimal{{ cleantm.custom.price_in_decimal.value }}Integer List{{ cleantm.custom.agelist.value | join:'&lt;br&gt;' }}&nbsp;Integer Single{{ cleantm.custom.age.value }}Single Line Text (list){{ cleantm.custom.specifications_of_product.value | join:'&lt;br&gt;' }}File&lt;a target='_blank' href='{{ cleantm.custom.file.value.url}}'&gt;{{ cleantm.custom.file.value.url | split: '/' | last | split:'?' | first }}&lt;/a&gt;Date and Time&nbsp;
{{ cleantm.custom.datetimesingle.value | date: '%A, %B %d, %Y at %l:%M %p %Z' }}
B. To reference the metafield directly (without dynamic data binding) :&nbsp;
You can use the standard metafield format: &nbsp;{{ product.metafields.namespace.key.value }}.
Example:&nbsp;If your metafield is in the custom namespace with key size, then use:&nbsp; {{product.metafields.custom.size.value }}This will directly render the metafield value for the current variant context.

Title: Dynamic Variant Metafields

The Clean Tables app supports displaying the value of any selected variant metafield, including those created by other apps.
&nbsp;A. To display a variant metafield using a dynamic field:Identify the namespace and key of the metafield.
Use the following format in your table content: {{cleantVariantm.namespace.key}}
Example:&nbsp;If your metafield has:&nbsp;Namespace: instructions&nbsp; and Key: wash,&nbsp;then use:&nbsp;

{{cleantVariantm.instructions.wash}}
This will automatically show the metafield value of the selected variant in the table.
B. To reference the metafield directly (without dynamic data field):&nbsp;You can use the standard metafield format: {{ variant.metafields.namespace.key.value }}

Example:&nbsp;If your metafield is in the custom namespace with key size, then use:&nbsp;

{{ variant.metafields.custom.size.value }}

This will directly render the metafield value for the current variant context.

Title: Placement Of Highlight Box

coming soon
Note: This is for advanced users who can work with Shopify liquid code and CSS styling language.
The Highlight Box can be placed at virtually any location on the product page. Its position can be manipulated by:
1. Changing the integration code location

2. Passing appropriate parameters in the integration code &nbsp; &nbsp;
There are two helpful integration parameters to manage the badge placement:
1. cleanhOuterClass: CSS classes passed using this parameter will be applied to the DIV containing the Highlight box.&nbsp;
We have the following in-built classes that can be used to manage the badge placement:
Class Name
Resultant CSS
clean-m-0margin:0rem;
clean-mr-0margin-right: 0rem;
clean-ml-0margin-left: 0rem;
clean-mt-0
margin-top: 0rem;clean-mb-0
margin-bottom: 0rem;clean-m-1
margin: .25rem;cleam-mr-1margin-right: .25rem;clean-ml-1
margin-left: .25remclean-mt-1margin-top: .25rem;clean-mb-1margin-bottom: .25rem;
Similarly, we can add classes with 2, 3, 4, and 5 suffixes to add margins of .5rem, 1rem, 1.5rem, and 3rem respectively. &nbsp;
Example integration code:

{% render 'cleanh', product: product, cleanhOuterClass: 'clean-mt-4 clean-mb-2' %}This will apply a top margin of 1.5rem and a bottom margin of .5rem Highlight Box container.
2. cleanhOuterStyle: Pass any custom CSS elements using this parameter and they will be applied to the Highlight Box container.
Example integration code:

{% render 'cleanh', product: product, cleanhOuterStyle: 'border: 1px solid black' %}This code can be used to add a black border to the Highlight Box.

Title: What Are Notes 

(coming soon)
Notes are short textual feature highlights of the product. They are similar to the feature bullets on Amazon.
If you’ve ever bought or sold on Amazon, there is no way you can miss them. They are on the page, often next to the product’s images. Each bullet point is separated by a symbol which makes it easier to highlight the different benefits of the product. They greatly enhance readability and draw focus to the main advantages of the product. In short, it’s a seller’s sales pitch.&nbsp;
Notes help you to create similar bullet points to highlight key features of the product. Apart from bullets, you can format the note text into short paragraphs with rich formatting. Notes are complementary to the main product description and can be placed anywhere on the product or collection pages.
Each product can have only one Note box.
Notes are available only for Pro Plans and above.
